# AI Arcade - Kodi screensaver

A screensaver that picks a NES ROM from a folder, teaches itself to play it with no human input,
and shows the result. Built from the specification in
[`../docs/aiarcade-spec.md`](../docs/aiarcade-spec.md); see the "AI Arcade" section of the
repository README for what it does and the settings.

- `third_party/nestopia/` - the Nestopia JG emulator core (GPL-2.0-or-later), compiled in and used
  through its class-based API, so the display and every training thread have their own emulator.
  `VERSION` names the upstream commit. `third_party/nlohmann/json.hpp` is nlohmann/json 3.11.3 (MIT).
- `src/Emu.h` - one NES: load, frame, 2 KB RAM, savestates.
- `src/Common.h` - RNG, motifs, the 16 x 15 network grid and the 11 x 8 Go-Explore cell key, CPU throttle.
- `src/Archive.h` - the Go-Explore archive (1500 cells, eviction that keeps the deepest cell's line).
- `src/Objectives.*` - learning "progress" from RAM: constants and clocks dropped, Spearman rank
  correlation with depth, de-duplication, percentile Value; death detection.
- `src/Neat.*` - NEAT: feed-forward genomes, speciation, sharing, stagnation, elitism, innovations.
- `src/Episode.h` - one controller playing from a start state; the same code scores genomes and
  plays the champion on screen.
- `src/Trainer.*` - the library scan and ROM choice, the FIND_GAMEPLAY / EXPLORE / LEARN / EVOLVE
  pipeline, persistence, and the training, helper and display threads.
- `src/ScreensaverAIArcade.cpp` - the Kodi shell: settings, the texture upload, HUD and fitness graph.
- `src/Font8x8.h` - the public-domain 8 x 8 font (font8x8_basic).
- `tests/emu_test.cpp` - speed, savestate round trip, and two emulators on two threads.
- `tests/arcade_test.cpp` - the whole pipeline with no Kodi, on a ROM or a folder.

    cmake -S . -B build-tools -DARCADE_KODI=OFF -DARCADE_TOOLS=ON && cmake --build build-tools -j8
    build-tools/emu_test game.nes
    build-tools/arcade_test game.nes /tmp/arcade-data 300 4 1.0   # 5 minutes, 4 threads, no CPU cap
    ./build_all.sh                    # macOS universal dylib and the arm64 Android .so

Settings are generated by `../tools/make_settings_aiarcade.py`; the icon and fanart by
`../tools/make_aiarcade_media.py`.
