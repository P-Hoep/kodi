# Lichen & Coral (OpenGL)

A native Kodi 21 screensaver that grows lichen and coral from published growth models. See the
main [README](../README.md#lichen--coral-opengl) for what it shows.

| File | What |
|---|---|
| `src/Lichen.h` | Open-DLA lichen colonies, Hill/Seminara radial growth, Jettestuen nucleation |
| `src/Reef.h` | Mistr–Bercovici-style reef/nutrient reaction–advection on a periodic grid |
| `src/Coral.h` | Merks polyp-oriented branching coral, and Laplacian DLA for the massive form |
| `src/ScreensaverLichenCoral.cpp` | Kodi wrapper, scene manager, GL renderer (GL 3.2 core / GL 2.1 / GLES 2) |
| `tests/sim_test.cpp` | standalone model checks and PPM snapshots (no Kodi or GL) |
| `build_all.sh` | builds the macOS universal dylib and the arm64 / armeabi-v7a libraries |

Settings are generated by `tools/make_settings_lichencoral.py` (run it for both add-ons; pass
`low` for the `.armv7` one). The models are simplified for real-time display.
