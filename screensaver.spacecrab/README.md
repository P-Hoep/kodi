# Space Crab (OpenGL)

A native Kodi 21 screensaver: an animated, rigged crab (or up to twelve) floating in empty space.
See the main [README](../README.md#space-crab-opengl) for what it shows.

| File | What |
|---|---|
| `src/CrabModel.h` | loads `resources/model/crab.bin`; poses the baked palette; CPU skinning fallback |
| `src/ScreensaverSpaceCrab.cpp` | Kodi wrapper, camera, crab motion, GL renderer (GL 3.2 core / GL 2.1 / GLES 2) |
| `resources/model/` | baked mesh + walk cycle and 2048² colour / normal JPEGs (generated) |
| `build_all.sh` | builds the macOS universal dylib and the arm64 / armeabi-v7a libraries |

`tools/make_crab_model.py` turns `crab.glb` into `resources/model/` for both add-ons. It
evaluates the skeleton itself (48 samples of the 0.48 s walk cycle), centres and scales the
crab to radius 1, and merges joints that always move together, so the palette is 55 joints
(165 vec4 uniforms) and fits GLES 2 GPUs with 256 vertex uniform vectors. GPUs with fewer get
CPU skinning and at most three crabs.

Settings are generated by `tools/make_settings_spacecrab.py` (run it for both add-ons; pass
`low` for the `.armv7` one).

Crab model: "Animated Crab rigged FREE" by TwilightFox (Sketchfab Standard licence).
