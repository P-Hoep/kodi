# Sand Clock v2 (OpenGL) - Kodi screensaver

A clock of sand with real grain physics, or of liquid digits that melt, run on the CPU so it is
light on TV sticks. See the "Sand Clock v2 (OpenGL)" section of the repository README for the
settings and the measurements.

- `src/Sand.h` - the sand (no Kodi / GL): one byte per cell plus an 8-byte motion record, grains
  with fixed-point velocity and sub-cell position, 16 x 16 activity chunks, 32-column strips in two
  passes on worker threads, the clock's crumbling, pouring and building, and the drain funnels.
- `src/Liquid.h` - the liquid (no Kodi / GL): a FLIP fluid with the digits as frozen particles
  that thaw, drip and condense, counting-sorted particles, band-parallel grid transfers, a pressure
  solve over a list of fluid cells, and a SIMD splat into an RGBA picture.
- `src/ClockFace.h`, `src/Glyphs.h`, `src/Colours.h` - the clock text, layout and rasterising, the
  Sand Clock fonts as run-length glyph masks (`../tools/make_sandclock_v2_fonts.py`), palettes.
- `src/WorkerPool.h` - the fork-join pool from Dancing Boids.
- `src/ScreensaverSandClock.cpp` - the Kodi wrapper: settings, a driver thread that steps the
  simulation while Kodi draws (60 steps a second), texture uploads and one quad with a sand or a
  liquid shader.
- `tests/sim_test.cpp` - threads vs one thread, angle of repose, collapse, complete digits, heap
  height and grain count, liquid stability and volume for every liquid and melt style, benchmark.

    c++ -O3 -std=c++17 -Isrc tests/sim_test.cpp -o /tmp/sandclock2_test -pthread && /tmp/sandclock2_test
    ./build_all.sh    # macOS universal dylib, arm64 .so, and ../screensaver.sandclock_v2.armv7 .so

Settings are generated by `../tools/make_settings_sandclock_v2.py` (both add-ons); the option
indices there match the lists and enums in `ScreensaverSandClock.cpp`, `Sand.h`, `Liquid.h` and
`Colours.h`.
