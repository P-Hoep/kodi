src/stb_image.h is Sean Barrett's stb_image (public domain / MIT), vendored
unchanged. src/json.hpp is a small JSON reader written for this repository.

resources/media/fonts contains textures generated from the Doto typeface,
which is licensed under the SIL Open Font License, Version 1.1. The licence
text is included as resources/media/fonts/Doto-OFL.txt; the font itself is a
variable font by Adam Jagosz.

Aircraft data is provided by the volunteer-run adsb.lol and OpenSky Network
APIs. It is used as-is and is not intended for navigation or flight safety.
