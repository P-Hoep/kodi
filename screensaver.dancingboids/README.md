# Dancing Boids (OpenGL) - Kodi screensaver

A native take on Netlight's [Dancing Boids](https://github.com/netlight/dancing-boids) macOS
screensaver: Reynolds boids (separation, alignment, cohesion) drawn as triangles pointing along
their flight, with a wandering lead point, hawks, up to four flocks, and a new flock fading in on
a timer. See the "Dancing Boids (OpenGL)" section of the repository README for the settings.

- `src/Boids.h` - the simulation (no Kodi / GL): SoA state, counting-sort grid with the data
  permuted into cell order, synchronous update split into ranges, neighbour cap with a per-boid
  rotated cell order (a fixed order biases every boid towards one corner).
- `src/WorkerPool.h` - a small fork-join pool for the per-step update.
- `src/ScreensaverDancingBoids.cpp` - the Kodi wrapper: settings, fixed time step, one streamed
  vertex buffer (position + packed RGBA), triangles or point sprites, ping-pong FBO trails, sky.
- `tests/sim_test.cpp` - grid vs all-pairs, threads vs single thread, flock health, benchmark.

    c++ -O2 -std=c++17 -Isrc tests/sim_test.cpp -o /tmp/boids_test -pthread && /tmp/boids_test
    ./build_all.sh    # macOS universal dylib, arm64 .so, and ../screensaver.dancingboids.armv7 .so

Settings are generated by `../tools/make_settings_dancingboids.py` (both add-ons); the option
indices there match the enums in `ScreensaverDancingBoids.cpp`.
