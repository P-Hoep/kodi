# Physarum v2 (OpenGL) - Kodi screensaver

The Physarum slime mould (Jeff Jones's agent model, the presets of the GPU Physarum add-ons) run on
the CPU so it is light on TV sticks. See the "Physarum v2 (OpenGL)" section of the repository
README for the settings and the measurements.

- `src/Physarum.h` - the simulation (no Kodi / GL): 16-bit fixed-point trail with a ghost border,
  16.16 positions and 32-bit angles, per-species direction tables, branch-free turning, batched
  agents counting-sorted by tile every 16 steps, integer diffuse/decay that writes the 8-bit picture.
- `src/WorkerPool.h` - the fork-join pool from Dancing Boids.
- `src/ScreensaverPhysarum.cpp` - the Kodi wrapper: settings, a driver thread that steps the
  simulation while Kodi draws, step credit at 30/60/120 steps a second, one texture upload per step
  and one quad with a fragment shader compiled per colour mode and species count.
- `tests/sim_test.cpp` - determinism, threads vs one thread, every preset forms a network, every
  start and species count runs, benchmark.

    c++ -O3 -std=c++17 -Isrc tests/sim_test.cpp -o /tmp/physarum_test -pthread && /tmp/physarum_test
    ./build_all.sh    # macOS universal dylib, arm64 .so, and ../screensaver.physarum_v2.armv7 .so

Settings are generated by `../tools/make_settings_physarum_v2.py` (both add-ons); the option
indices there match the lists and enums in `ScreensaverPhysarum.cpp`, `Physarum.h` and `Presets.h`.
